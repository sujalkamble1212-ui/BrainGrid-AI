# 🧠 Thinkoku - Sudoku Solver

**Think smarter. Solve faster.**

Thinkoku is an interactive and visually engaging Sudoku Solver web application built using HTML, CSS, and JavaScript. It allows users to input Sudoku puzzles and solves them using a backtracking algorithm with smooth animation and real-time validation.

---

## 🚀 Features

* 🔢 9×9 Interactive Sudoku Grid
* ⚡ Step-by-step solving animation
* 🚫 Real-time invalid input highlighting
* ⌨️ Arrow key navigation for smooth movement
* ➡️ Auto-focus to next cell while typing
* 🧹 Clear grid functionality
* 🎨 Modern dark-themed UI

---

## 🧠 How It Works

The solver uses a **backtracking algorithm**:

* Finds empty cells in the grid
* Tries numbers from 1 to 9
* Validates each number based on Sudoku rules
* Backtracks if a number doesn't fit

## 🎯 Usage

1. Enter Sudoku numbers manually
2. Invalid inputs will be highlighted in red
3. Click **Solve** to see animated solution
4. Use arrow keys for navigation
5. Click **Clear** to reset the grid
